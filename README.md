### 🇪🇸 Sobre mí

Desarrollador Full Stack de **Rosario, Argentina** y fundador de **Code & Lens Solutions**. Diseño y mantengo productos en producción: un **SaaS multi-tenant de gestión comercial** con backend Laravel y apps Flutter que funcionan offline, un sistema de **gestión clínica para residencias geriátricas** y una **plataforma educativa** con alumnos reales. También soy docente de programación frontend y backend.

- 🔭 Hoy: APIs en Laravel + apps Flutter para Android, iOS, Windows, Linux y web.
- 🧩 Integraciones: Mercado Pago (pagos, suscripciones, Point), Auth0, Google Sign-In, WebSockets (Reverb / Socket.io), Zipnova.
- 🚀 Deploy propio en VPS con Nginx y PM2.
- 🎓 Docente de React, Node.js/Express y MongoDB.
